### Session Title
> Fuzzy Regression Methods

### Presenter(s)
> Dr Tony Beatton, ARC Centre for Behavioural Insights for Technology Adoption (ARC BITA) at QUT

### Abstract
> Fuzzy regression methods are extensions of classical regression techniques designed to handle uncertainty, vagueness, and imprecision in data. The method establishes a fuzzy functional relationship between dependent and independent variables, where the input data can be either crisp or fuzzy. It is widely used in forecasting, decision-making, and modelling when data is incomplete, noisy, or linguistically described.
>
> This interactive session will overview Fuzzy Methods then focus on two applications in Economics.
