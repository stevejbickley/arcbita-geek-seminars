# Proofreading

Read-only. Report problems, do not fix them, unless asked to fix them.

## Order of passes

Run these separately. Trying to catch everything in one read catches nothing.

1. **Correctness.** Typos, agreement, tense, punctuation.
2. **Terminology.** The same thing called by the same name throughout. A concept renamed halfway through a paper is the most common drift in a multi-session draft.
3. **Numbers.** Every figure in the text checked against the table it comes from. Percentages that should sum. Sample sizes quoted consistently.
4. **References.** Every in-text citation present in the bibliography, and the reverse. Years and author spellings consistent.
5. **Structure.** Cross-references resolve. Tables and figures are all referred to in the text. Section numbering is intact.
6. **Clarity.** Sentences that require a second read. Paragraphs making more than one point. Claims that go further than the evidence.

## Reporting

One list, grouped by pass, each item with a location.

```
Numbers
  p.14, para 2 — text says 8.7pp, Table 3 says 8.9pp
  p.22 — "roughly a third" but the table gives 41%

Terminology
  "effective district magnitude" (p.3) vs "effective constituency
  size" (p.11, p.17) — same concept, two names
```

## Do not

- Rewrite prose while proofreading. Those are different jobs and mixing them hides errors.
- Report style preferences as errors. Say which is which.
- Report a number as wrong without naming the source it disagrees with.
