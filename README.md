### Folder layout:
```
/sessions/YYYY-MM-DD-topic/
  abstract.md | 
  slides/ |                # presentation slides (e.g. .pptx/.pdf file)
  demo/ |                  # code demos, scripts, notebooks, etc. used in the session (if any)
  /recordings/ |           # video/audio recordings of sessions (if/as available)
  /transcripts/ |          # text transcripts of sessions (if/as available)
```

---

### Workflow:
1. Propose a session:
    * To propose a new Geek Seminar session (either one you’d like to deliver yourself, or one you’d like someone else to deliver), open a new issue at this [link](https://github.com/stevejbickley/arcbita-geek-seminars/issues) and include a short abstract plus 1-3 expected learning outcomes.
2. Before the session:
    * Create the session folder by copying /templates/session to /sessions/YYYY-MM-DD-topic/, then update the abstract.md, add slides, and any demo code, and include the registration link plus Zoom/room details in that folder.
3. After the session:
    * After the session, add the recording to /recordings (or a link stub), upload the transcript to /transcripts (if/as available), then push your changes to GitHub on a new branch (e.g., sessionX). The repo admins/moderators will then review the pull request and merge updates into main.
